# SIPROTEC 5 – Generator Differential Protection (ANSI 87G)

## 📘 Technical Reference

This repository contains a technical reference on **Generator Differential Protection (ANSI 87G)** for Siemens **SIPROTEC 5** protection systems.

The document is prepared based on information from the **SIPROTEC 5 technical manual** and is intended for technical learning, reference, and understanding of the protection function.

---

## ⚡ Generator Differential Protection

Generator differential protection is used to detect **internal faults within the protected generator zone** by comparing the currents entering and leaving the protected zone.

The document covers important concepts related to the SIPROTEC 5 generator differential protection function, including:

* Differential protection principle
* Differential current
* Restraint current
* Operating characteristic
* Pickup characteristics
* Differential protection stages
* **I-DIFF**
* **I-DIFF Fast**
* **I-DIFF Unrestrained**
* Protection operating conditions
* Relevant protection parameters
